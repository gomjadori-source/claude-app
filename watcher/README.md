# 🔔 네이버 예약 빈자리 알림 봇

구글 시트에 가게/날짜/시간/인원을 적어두면, GitHub Actions가 10분마다 네이버 예약 페이지를 확인해서 **자리가 새로 생기는 순간 텔레그램으로 알려주는** 도구입니다.

- 알림 전용입니다. **예약을 대신 하지 않고**, 예약 페이지도 자동으로 열지 않습니다. 알림의 링크를 직접 눌러 예약하세요.
- 자리가 "없음 → 있음"으로 **바뀌는 순간에만** 알립니다. 계속 열려 있는 자리는 다시 알리지 않고, 닫혔다 다시 열리면 새로 알립니다.
- KST 새벽 1시~7시 알림은 무음(진동/소리 없음)으로 도착합니다.
- 감시 주기: 09:00~24:00는 10분, 00:00~09:00는 1시간.

## 처음 설정 (한 번만, 약 20분)

### 1. 텔레그램 봇 만들기

1. 텔레그램에서 `@BotFather` 검색 → `/newbot` 입력 → 봇 이름/아이디 정하면 **토큰**이 발급됩니다. (`123456789:AAH...` 형태) → 이게 `TELEGRAM_TOKEN`
2. 방금 만든 봇을 검색해서 **아무 메시지나 하나 보냅니다.** (이걸 해야 봇이 나에게 메시지를 보낼 수 있음)
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열면 JSON 안에 `"chat":{"id":123456789...}` 가 보입니다 → 이 숫자가 `TELEGRAM_CHAT_ID`

### 2. 구글 시트 만들기

1. 새 스프레드시트를 만들고 **1행에 컬럼명**을 정확히 이렇게 적습니다:

   | 상태 | 가게명 | URL | 날짜 | 시간 | 필요인원 |
   |---|---|---|---|---|---|
   | O | 성수동파스타 | https://booking.naver.com/booking/6/bizes/... | 2026-08-20 ~ 2026-08-24 | 18:00 ~ 20:00 | 2 |
   | O | 을지로오마카세 | https://booking.naver.com/booking/6/bizes/... | 2026-09-01, 2026-09-05 | 12:00 | 4 |

   - **상태**: `O`인 행만 감시. 잠시 끄고 싶으면 `X` 등 다른 값으로.
   - **URL**: 네이버 지도/검색에서 가게 → "예약" 버튼 → 열리는 `booking.naver.com/...` 주소 전체 복사.
   - **날짜**: `2026-08-20` 하나, `2026-08-20 ~ 2026-08-24` 범위, 쉼표로 여러 개 모두 가능.
   - **시간**: 형식은 날짜와 동일 (`18:00` / `18:00 ~ 20:00` / 쉼표). **비워두면 아무 시간이나 알림.**
   - **필요인원**: 이 숫자 이상 잔여석이 있을 때만 알림. 비우면 1.

2. 시트 주소(`https://docs.google.com/spreadsheets/d/...`)를 복사해둡니다 → `SHEET_URL`
3. 시트는 **비공개로 유지**하세요. 저장소가 공개여도 감시 목록은 시트에만 있어서 노출되지 않습니다.

### 3. 구글 서비스 계정 만들기 (봇이 시트를 읽을 수 있게)

1. https://console.cloud.google.com 접속 → 상단에서 **새 프로젝트** 생성 (이름 아무거나)
2. 검색창에 **"Google Sheets API"** → 선택 → **사용 설정(Enable)**
3. 좌측 메뉴 **IAM 및 관리자 → 서비스 계정 → 서비스 계정 만들기** (이름 아무거나, 역할은 부여 안 해도 됨)
4. 만든 계정 클릭 → **키(Keys) 탭 → 키 추가 → JSON** → JSON 파일이 다운로드됩니다 → 이 파일의 **내용 전체**가 `GOOGLE_CREDENTIALS`
5. JSON 안의 `"client_email"` 값(`...@....iam.gserviceaccount.com`)을 복사해서, **구글 시트의 공유 버튼**으로 이 이메일을 **뷰어** 권한으로 초대합니다.

### 4. GitHub Secrets 등록

저장소 → **Settings → Secrets and variables → Actions → New repository secret** 에서 4개 등록:

| 이름 | 값 |
|---|---|
| `TELEGRAM_TOKEN` | 1번에서 받은 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 1번에서 확인한 채팅 ID |
| `SHEET_URL` | 2번의 시트 전체 주소 |
| `GOOGLE_CREDENTIALS` | 3번 JSON 파일의 내용 전체 (열어서 전부 복사-붙여넣기) |

### 5. 켜기 & 테스트

1. 저장소 **Actions 탭**에서 워크플로 실행을 허용(처음이면 초록 버튼 하나 눌러야 함)
2. **Actions → Naver Booking Watcher → Run workflow**로 즉시 1회 실행해봅니다.
3. 시트에 적은 조건에 빈자리가 실제로 있으면 텔레그램 알림이 옵니다. 자리가 없으면 조용한 게 정상입니다 — 로그에 `확인 완료`가 찍혔는지 보세요.

## 평소 사용법

- **가게 추가/제거** = 시트에서 행 추가하거나 상태를 바꾸면 끝. 코드는 안 건드립니다. (폰의 스프레드시트 앱에서도 가능)
- 알림이 오면 → 버튼 눌러서 네이버에서 직접 예약.
- 매일 아침 9시쯤 "감시 중 N개, 각 타겟 상태" 요약이 옵니다. 이게 안 오면 Actions 탭을 확인하세요.

## 문제가 생기면

| 증상 | 의미 / 조치 |
|---|---|
| "⚠️ 자리 정보를 읽지 못하고 있어요" + 스크린샷 | URL이 틀렸거나 페이지 구조가 특이한 경우. 스크린샷으로 페이지가 제대로 떴는지 확인 |
| "파서가 해석 못 한 응답 원본" 파일이 옴 | 그 파일을 개발자(또는 Claude 세션)에게 전달하면 파서를 그 구조에 맞게 보정할 수 있음 |
| "❌ 구글 시트를 읽지 못했습니다" | 서비스 계정을 시트에 공유했는지, `GOOGLE_CREDENTIALS`에 JSON 전체가 들어갔는지 확인 |
| 아침 요약이 안 옴 | Actions 탭에서 워크플로가 실패/비활성화됐는지 확인. 저장소에 60일간 커밋이 없으면 GitHub가 예약 실행을 끄는데, 이 봇은 state.json을 주기적으로 커밋하므로 보통 해당 없음 |

## 알아둘 점

- **실시간이 아닙니다.** GitHub의 예약 실행은 수 분씩 밀릴 수 있어, 체감 감시 간격은 10~20분입니다. 오픈런처럼 초 단위로 사라지는 자리보다는, 취소표처럼 시간 단위로 나는 자리에 적합합니다.
- 이 저장소는 공개여도 안전하게 설계되어 있습니다: 토큰/시트주소/구글키는 Secrets에만 있고, Actions 로그의 가게명은 마스킹되며, `state.json`에는 해시값만 기록됩니다.
- `state.json` 커밋(`chore: update watcher state`)이 주기적으로 쌓이는 것은 정상 동작입니다.
- 네이버 예약 페이지 응답 구조는 예고 없이 바뀔 수 있습니다. 봇이 자리를 읽지 못하게 되면 위 표의 절차대로 경고가 오니, 조용히 죽는 일은 없습니다.
